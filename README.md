# English Dictation Practice

A pure frontend English numbers and dates dictation training tool. Listen to audio generated by the Web Speech API, then type or choose what you heard. Each session generates 10 random items.

Built with Vue 3 + TypeScript + Vite. Ready to deploy to GitHub Pages.

## Features

- **Three modes**: Numbers only, Dates only, or Mixed (5 numbers + 5 dates)
- **Two input methods**: Typing (fuzzy matching) or Multiple Choice (4 options)
- **Full number range**: 0 to millions, including decimals
- **Date varieties**: US format ("March fifteenth, twenty twenty-four") and UK format ("the fifteenth of March, twenty twenty-four"), both randomly assigned
- **Year pronunciation variants**: "twenty twenty-four" or "two thousand twenty-four" — chosen at random
- **Audio replay**: Listen as many times as you need
- **Dark mode**: Respects system color scheme preference

## How It Works

```
Select a mode → Choose input method → 10 random questions →
  Listen → Answer → Immediate feedback → Score summary
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | [Vue 3](https://vuejs.org/) (Composition API + `<script setup>`) |
| Language | [TypeScript](https://www.typescriptlang.org/) |
| Build | [Vite](https://vitejs.dev/) |
| Audio | [Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) (SpeechSynthesis) |
| Styling | CSS (global + scoped, no framework) |

No external runtime dependencies beyond Vue.

## Getting Started

### Development

```bash
pnpm install
pnpm dev        # Start dev server
pnpm build      # Type-check + production build
pnpm preview    # Preview production build
```

### Deploy to GitHub Pages

1. Create a repository named `dictation_app` on GitHub
2. Push the project to GitHub:
   ```bash
   git init
   git add .
   git commit -m "init"
   git remote add origin https://github.com/<username>/dictation_app.git
   git push -u origin main
   ```
3. Build the project:
   ```bash
   pnpm build
   ```
4. Deploy the `dist/` folder to GitHub Pages:
   - **Option A**: Push `dist/` to a `gh-pages` branch
   - **Option B**: Use GitHub Actions (add a workflow that builds on push to `main`)
   - **Option C**: In repo Settings → Pages → set source to GitHub Actions, then use [peaceiris/actions-gh-pages](https://github.com/peaceiris/actions-gh-pages)

   The `base` path is pre-configured as `/dictation_app/` in `vite.config.ts`. Change it if your repo has a different name.
